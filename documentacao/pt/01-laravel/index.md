# Laravel

Notas de backend, estrutura de aplicação e comandos usados em projetos Laravel.

## Áreas

- **Comandos**: Artisan, migrations, cache e filas.
- **Eloquent**: modelos, scopes, relações e queries.
- **Boas práticas**: organização, validação, autorização e convenções.

## Checklist Base

- Definir `.env`.
- Correr migrations.
- Confirmar rotas com `php artisan route:list`.
- Limpar caches quando algo parece antigo.

## Comandos Frequentes

```bash
php artisan serve
php artisan migrate
php artisan optimize:clear
php artisan test
```

# Vue

Notas de frontend para componentes, composables, estado e padrões usados com Inertia.

## Áreas

- **Componentes**: estrutura, props, eventos e slots.
- **Composables**: lógica reutilizável.
- **Modais**: dialogs controlados com props e emits.
- **Padrões**: formulários, listas, filtros e modais.

## Comandos

```bash
npm install
npm run dev
npm run build
```

# Novo Projeto

## Laravel + Vue + Inertia

```bash
composer create-project laravel/laravel nome-do-projeto
cd nome-do-projeto
composer require inertiajs/inertia-laravel
npm install
```

## Checklist

- Configurar `.env`.
- Criar base de dados.
- Instalar stack frontend.
- Confirmar `npm run dev`.
- Confirmar `php artisan serve`.

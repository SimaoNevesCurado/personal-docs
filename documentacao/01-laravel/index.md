# Laravel

Backend notes, application structure and commands used in Laravel projects.

## Areas

- **Commands**: Artisan, migrations, cache and queues.
- **Eloquent**: models, scopes, relationships and queries.
- **Best practices**: structure, validation, authorization and conventions.

## Base Checklist

- Set up `.env`.
- Run migrations.
- Check routes with `php artisan route:list`.
- Clear caches when something looks stale.

## Frequent Commands

```bash
php artisan serve
php artisan migrate
php artisan optimize:clear
php artisan test
```
